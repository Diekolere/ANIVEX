# Project: Anime Community Universe

## Vision
Build an immersive, anime-inspired social community that combines cinematic storytelling with a familiar social feed.

The experience should feel original, exciting, polished, and designed by someone who genuinely loves anime.

## Technology
- React
- TypeScript
- Vite
- Tailwind CSS v4
- GSAP for advanced animation and scroll-based storytelling
- Lucide React for icons when needed

## Design Direction
- Combine cinematic anime-inspired environments with a modern social platform.
- Use a dark foundation with carefully chosen accent colours.
- Let different anime-inspired sections have their own visual atmosphere.
- Use dramatic typography, layered imagery, depth, and intentional movement.
- Avoid generic AI-looking designs, excessive cards, excessive gradients, and meaningless animations.
- Do not make every element glow or move.
- Make the design distinctive rather than copying an existing platform.

## Experience
- Create a cinematic introduction with a Skip Intro option.
- Build a visually engaging landing page.
- Include a community feed with demo cosplay posts, fan art, anime edits, and short videos.
- Include anime discovery sections with distinct visual atmospheres.
- Create demo community rooms for different anime.
- Include mock group conversations and interactive community elements.
- Make buttons, navigation, images, and video controls behave meaningfully.
- Clearly distinguish demo interactions from real backend functionality.

## Animation
- Use smooth, intentional transitions.
- Explore layered parallax, scroll-triggered reveals, cinematic scene changes, and image transformations.
- Keep animations performant and responsive.
- Respect reduced-motion accessibility preferences.
- Avoid excessive animation that makes navigation difficult.

## Code Quality
- Use reusable React components.
- Keep TypeScript types clear.
- Organise code into sensible components and folders.
- Avoid putting the entire application into one component.
- Clean up animation contexts and event listeners when components unmount.
- Use local assets where available.
- Do not install unnecessary dependencies.

## Responsiveness and Accessibility
- Design for mobile first, then tablet and desktop.
- Prevent horizontal overflow.
- Ensure readable text, accessible controls, and keyboard navigation.
- Make touch interactions work properly on mobile.
- Optimise media and animation performance.

## Content and Copyright
- Use original, licensed, or otherwise authorised imagery and video.
- Do not assume anime footage or artwork is free to redistribute.
- Use clearly identified demo content for the portfolio prototype.

## Development Workflow
- Inspect existing files before making changes.
- Build the experience in stages rather than generating the entire application at once.
- Preserve working code when making changes.
- Run the production build and resolve errors after significant changes.
- Explain major changes briefly.
